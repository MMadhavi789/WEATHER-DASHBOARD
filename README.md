# Weather Dashboard

A simple weather dashboard application built using React.js.

## Features
- Search weather by city
- Displays temperature, humidity, and wind speed
- Dynamic weather icons
- Prevents empty search submissions
- Handles invalid city names
- Handles invalid API responses
- Responsive UI design

## Technologies Used
- React.js
- CSS
- OpenWeather API

## How to Run

1. npm install
2. npm start
